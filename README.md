# 续境 · XuJing

一个本地优先的个人桌面工作管理工具，让任务、SOP 步骤、专注时间和素材版本留在同一个工作空间。

## 下载

**[下载 macOS Apple 芯片安装包](https://github.com/shutongwang/xujing/releases/latest)**

当前为 **0.1.0 预览版**，适用于 Apple Silicon（M 系列芯片）Mac，暂不提供 Intel Mac 或 Windows 安装包。

打开 DMG，将「续境」拖入「应用程序」，之后直接从应用程序或程序坞启动，无需终端。

本版本尚未进行 Apple 签名和公证。macOS 可能阻止首次启动；请仅在确认下载来源可信后，按系统提示在「系统设置 → 隐私与安全性」中允许打开。无需关闭系统安全保护。

## 可以做什么

- 按截止日期和重要程度排列任务，记录当天与累计投入。
- 将逐行填写的 SOP 转换为步骤流程，保留完成时间、阶段用时和附注。
- 使用正计时、倒计时或番茄钟，回顾一天的工作节奏。
- 在项目内管理素材与成品版本，拖拽添加文件。
- 通过时间轴、统计图和基于规则的自然语言分析进行每日复盘。
- 简体中文界面，Art Deco 风格。

## 数据与隐私

个人任务和日志保存在自己的电脑上。安装包不附带开发者的任务数据库或私人素材。素材通常以本地文件引用方式管理，请自行备份原文件。

可选的 AI 功能需要自行配置服务；调用时相关内容可能发送到所配置的服务商。每日复盘主要采用本地规则分析，并非全部由大模型生成。

预览版建议定期备份。退出应用后，备份 `~/Library/Application Support/continuum-workbench/` 数据目录及原始素材。
